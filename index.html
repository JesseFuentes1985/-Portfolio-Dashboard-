About

Why this dashboard exists and how to keep it updated.

This site is built to show a snapshot of my work across projects and to make it easy for hiring teams to see what I'm shipping.

It uses a static frontend and can be hosted on GitHub Pages. For live Asana data, the recommended approach is to fetch Asana data on a secure backend (GitHub Actions / serverless function) and commit a small JSON snapshot.

The data folder (not yet created) can be used to store a asana.json file that powers the visualizations without exposing an API token.

Built with HTML, CSS, and vanilla JavaScript. Hosted on GitHub Pages.
